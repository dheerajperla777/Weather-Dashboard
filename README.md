Weather Dashboard

About

A weather dashboard that allows users to search for a city and view its current weather information.

Features

- Search weather by city name
- Display temperature
- Display humidity
- Display wind speed
- Show weather conditions
- Handle invalid cities and API errors

Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Weather API

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Ensure an internet connection is available.
4. Enter a city name and click Search.

Project Purpose

To practice working with external APIs, asynchronous JavaScript, and dynamic web interfaces.
